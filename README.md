# شجره‌نامه — نمونه اولیه

این مخزن شامل پیش‌نمایش وب و کد اولیه اپ اندروید با Flutter است.

## دریافت APK اندروید
پس از ثبت تغییر در پوشه `mobile`، GitHub Actions به‌صورت خودکار نسخه APK را می‌سازد:
1. وارد زبانه **Actions** مخزن شوید.
2. اجرای **Build Android APK** را باز کنید.
3. پس از موفقیت ساخت، از بخش **Artifacts** فایل `shajareh-android-apk` را دریافت کنید.
4. فایل ZIP را باز کنید؛ فایل `app-release.apk` داخل آن است.

برای ساخت مجدد هم از Actions، گزینه **Run workflow** را انتخاب کنید.

## وضعیت این نسخه
این APK یک نمونه اولیه نمایشی است. داده‌ها ساختگی‌اند و برنامه هنوز به API، پایگاه داده، ورود پیامکی یا فضای ذخیره‌سازی واقعی متصل نیست. اطلاعات واقعی خانوادگی را وارد نکنید.

## وب
فایل `index.html` پیش‌نمایش وب فارسی را ارائه می‌کند.
