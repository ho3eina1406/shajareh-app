# شجره‌نامه — نمونه اولیه نمایشی

این مخزن شامل یک نمونه اولیه فارسی، راست‌چین و واکنش‌گرا از اپلیکیشن شجره‌نامه است.

## مشاهده نسخه نمایشی
فایل [index.html](./index.html) را باز کنید. برای استفاده از نصب‌پذیری و حالت آفلاین، پروژه را روی یک میزبان استاتیک با HTTPS منتشر کنید.

## انتشار آسان با GitHub Pages
1. وارد تنظیمات مخزن در GitHub شوید.
2. از بخش **Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه **main** و پوشه **/(root)** را انتخاب و ذخیره کنید.
4. پس از چند دقیقه، نشانی انتشار در همان صفحه نمایش داده می‌شود.

## امکانات موجود در پیش‌نمایش
- رابط فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- صفحه خانه، شجره خانوادگی نمونه، اعضا، خبرها و خاطرات، آرشیو و پیام‌ها
- جست‌وجوی نمونه در افراد و بازکردن کارت اطلاعات
- پوسته اولیه قابل نصب (PWA) و کش پایه برای حالت آفلاین

## نکته مهم
این فقط **نمونه رابط کاربری** است؛ هنوز سرور، پایگاه داده، ورود پیامکی، حساب کاربری، ذخیره‌سازی واقعی، ارسال پیام و مدیریت دسترسی به آن متصل نشده‌اند. همه نام‌ها، آمارها و رویدادها ساختگی‌اند. اطلاعات واقعی خانوادگی را در این نسخه وارد نکنید.

## مسیر توسعه بعدی
اتصال API مبتنی بر ASP.NET Core، پایگاه داده PostgreSQL، احراز هویت امن، مدل دقیق روابط خانوادگی و ذخیره‌سازی خصوصی فایل‌ها.
